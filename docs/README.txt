HASTINGS HERITAGE QR LANDMARK TEMPLATE

GITHUB PAGES
This package is arranged for GitHub Pages with the publishing source set to:
- Branch: main
- Folder: /docs

The live website files are inside docs/.

Open docs/index.html in a browser for the original artist banner page. The 13 additional banner pages are in docs/artwork-01/ through docs/artwork-13/.

FOLDER LAYOUT
- docs/index.html: project home and template overview
- docs/landmarks.css: shared styling for every page
- docs/artwork-01/ to docs/artwork-13/: additional artist banner pages
- docs/images/net-shops/hero.jpg: banner artwork image
- docs/images/net-shops/historic.jpg: optional historic landmark image
- docs/README.txt: copy of these instructions available from the website

TO ADD A LANDMARK
1. Copy one of the docs/artwork-##/ folders and rename it for the landmark, e.g. docs/hastings-castle/.
2. Edit the banner, artist name, age, group, description and winning-work prompts in its index.html.
3. Complete the landmark context and Norman Trail location section at the bottom of the page.
4. Copy docs/images/net-shops/ to docs/images/hastings-castle/ and replace hero.jpg and historic.jpg.
5. Update the image folder name in the new page paths, if needed.
6. Point the physical QR code at the landmark folder URL.

The included JPGs are deliberately simple placeholders, not third-party photographs.
