HASTINGS HERITAGE QR LANDMARK TEMPLATE

Open index.html in a browser for the project home. Open net-shops/index.html for the reusable artist banner page.

FOLDER LAYOUT
- index.html: project home and template overview
- css/landmarks.css: shared styling for every page
- net-shops/index.html: copyable artist banner template
- images/net-shops/hero.jpg: banner artwork image
- images/net-shops/historic.jpg: optional historic landmark image

TO ADD A LANDMARK
1. Copy the net-shops folder and rename it for the landmark, e.g. hastings-castle.
2. Edit the banner, artist name, age, group, description and winning-work prompts in index.html.
3. Complete the landmark context and Norman Trail location section at the bottom of the page.
4. Copy images/net-shops/ to images/hastings-castle/ and replace hero.jpg and historic.jpg.
5. Update the image folder name in the new page paths, if needed.
6. Point the physical QR code at the landmark folder URL.

The included JPGs are deliberately simple placeholders, not third-party photographs.
