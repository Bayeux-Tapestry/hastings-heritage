HASTINGS HERITAGE QR LANDMARK TEMPLATE

Open net-shops/index.html in a browser. It is a reusable landmark profile template.

FILES
- css/landmarks.css: shared styling for every landmark page
- net-shops/index.html: landmark profile template
- images/net-shops/hero.jpg: replace with your current photograph
- images/net-shops/historic.jpg: replace with a licensed historic image

TO ADD A LANDMARK
1. Copy the net-shops folder and rename it, e.g. hastings-castle.
2. Edit the banner, artist name, age, group, description and winning-work prompts in index.html.
3. Complete the landmark context and Norman Trail location section at the bottom of the page.
4. Create images/hastings-castle/ and add hero.jpg and historic.jpg.
5. Update the two image paths in the landmark HTML if needed.
6. Point the physical QR code at the landmark folder URL.

The included JPGs are deliberately simple placeholders, not third-party photographs.
